\section{Mapping from version 1.3}\label{app:mapping}
Each of the 85 requirements of version 1.3 appears once. ``Split'' means the original bundled several obligations that are now separate requirements; ``moved'' means the content is unchanged but lives in another part; ``kept'' means one successor with the same obligation. Requirements marked new in the text have no version 1.3 predecessor, or strengthen one (for example \rr{POL-012}, \rr{DEC-008}).

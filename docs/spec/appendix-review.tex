\section{Review response (2.0 to 2.1)}\label{app:review}
An external review of version 2.0 raised seven prioritized findings, decisions on the author's choices and several contract clarifications. This table records how each was handled. Two sourced claims were checked before acting: Cerbos evaluates principal policies first and treats their explicit result as final for that action, and a cancelled synchronous wait leaves a transaction visible but not yet replicated. The reviewer received the PDF only, so \texttt{vectors/} and \texttt{tools/check\_spec.py} were not examined; the checker is extended in this revision (\rr{GATE-003}).

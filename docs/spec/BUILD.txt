  vectors/decisions.json                    Machine-readable test vectors

Build (tested with Tectonic 0.17.0, Python 3.13):
  python3 -I tools/check_spec.py     # validates and regenerates generated/*.tex
  tectonic main.tex                  # writes main.pdf; copy it to the versioned name

check_spec.py also rejects a requirement whose test is first verified in a later phase.
It reads the 1.3 source for the mapping check; pass --v13 PATH if it is not at
/Users/jb-sec/Documents/fine-grained-access-spec/fine-grained-access-spec.tex
(without it, the check only verifies that mapping.csv has 85 rows).

Compilation and the check validate the document, not the unbuilt platform. The test
vectors have not been run against any implementation.
